# Security Policy

## Supported Versions

bigoci is pre-release and has no published versions yet. Until a release
exists, security fixes land on `master` only. Once releases begin, only the
latest release is supported.

## Reporting a Vulnerability

Report vulnerabilities privately through [GitHub's private vulnerability
reporting](https://github.com/componere/bigoci/security/advisories/new) for
this repository.

Do not use public GitHub issues, pull requests, discussions, or other public
channels for vulnerability reports.

When reporting a vulnerability, include as much of the following as possible:

- affected version or commit
- a description of the issue and the security impact
- steps to reproduce or a minimal proof of concept
- any relevant logs or traces
- any suggested mitigations or fixes, if available
